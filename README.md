# Грехи и стихи Библии

Сайт для молодёжи церкви: список грехов и все стихи Библии о каждом из них (Синодальный перевод).

Сайт: https://michhall2008-sketch.github.io/Bible-grehi/

- `index.html` — сайт (одна страница).
- `data.json` — грехи и стихи. Обновляется раз в сутки из закрытой Google Таблицы (`.github/workflows/update-data.yml`, `scripts/build_data.py`).
